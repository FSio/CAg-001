IDEA: 
Creation of presentations based on HTML (SPA) Single-Page App from a PPTX file or from a prompt

Instructions
Go to latest folder and choose donwload the zip file locally
then

Unzip the zip file

then change of directory

    cd pptx2pwa_v3

create a folder called "input". Inside of this folder copy the PPTX file to convert

then install a local server 

    npm install

then start the local server

    npm start

now opne your browser and navigate to http://localhost:3000

Once you open the app, load the Claude API keys and choose the PDF file to convert

then at the end apply on Generate button

After some seconds your will have the requested presentation
